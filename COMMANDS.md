# Что умеет Джарвис

Начинайте с «Джарвис, …». После ответа 8 секунд можно продолжать без имени. Формулировки свободные: если
фраза не похожа на готовую команду, её переводит в команды локальная модель (и запоминает).

**Управление разговором**
- Перебить: «Джарвис, …» с новой командой, или просто «стоп / хватит / подожди» — и сразу новая команда.
  Когда вы говорите поверх ответа, Джарвис сразу становится тише, чтобы расслышать вас.
- «ещё раз» — повторить прошлую команду; «повтори» — повторить ответ; «а завтра?», «а в Казани?» — уточнение.
- «не то» — отменить последнее действие и забыть, как была понята фраза; «верни как было» — просто отменить.
- Опасные действия (выключение ПК, удаление списка, завершение процесса) — только после «да».

## Компьютер

| Что | Как сказать |
|---|---|
| Приложения и сайты | «открой телеграм», «запусти стим», «зайди на habr.com», «закрой браузер» |
| Окна | «сверни всё», «разверни хром на весь экран», «переключись на телеграм», «какие окна открыты» |
| Звук | «громче / тише», «выключи звук», «пауза», «следующий трек», «сделай дискорд тише», «выключи звук в браузере» |
| Музыка из папки «Музыка» | «включи believer», «включи музыку», «включи что-нибудь спокойное» (подпапки = плейлисты), «что играет» |
| Питание | «заблокируй компьютер», «спящий режим», «выключи компьютер через час», «отмени выключение» |
| Состояние ПК | «сколько места на диске», «что грузит компьютер», «заряд батареи», «какой у меня ip» |
| Файлы (только чтение) | «сколько фото в загрузках», «что в загрузках», «найди файл отчёт», «открой папку загрузки» |
| Поиск в браузере | «найди в яндексе рецепт борща», «найди на ютубе обзор 4060», «загугли …» |

Джарвис не умеет изменять, перемещать и удалять файлы; читать может только разрешённые папки (Настройки → Папки).

## Текст

| Что | Как |
|---|---|
| Диктовка | **Ctrl+Alt+D** — сигнал, говорите: каждая фраза печатается там, где курсор, сразу после паузы. Ещё раз Ctrl+Alt+D или 30 с тишины — конец. Можно и зажать клавиши: текст вставится при отпускании. Голосом: «диктовка». |
| Напечатать фразу | «напечатай привет, буду через 10 минут» |
| Выделенный текст | выделите и скажите: «переведи», «объясни выделенное», «перескажи», «исправь ошибки», «перепиши вежливо», «прочитай выделенное» |
| Экран | **Ctrl+Alt+S** или «что на экране», «что это за ошибка» — выделите область мышью; «скопируй текст с экрана» |

## Браузер

Нужно расширение из папки `browser_extension` — «подключи браузер» (см. README). Задачи идут в фоне: можно
говорить с Джарвисом о другом, о результате он скажет сам и оставит карточку со ссылками.

| Что | Как сказать |
|---|---|
| Товары | «найди на озоне наушники до 3000 с хорошими отзывами», «сравни цены на робот-пылесос на маркете», «сколько стоит айфон 15 на вайлдберриз», «положи в корзину на вб зарядку» |
| Видео | «включи на ютубе обзор RTX 5070» — найдёт, откроет окно и включит |
| Любая задача | «сделай в браузере подборку статей про Rust», «зайди на сайт … и …» |
| Открытая страница | «перескажи эту статью», «о чём это видео», «что на этой странице про доставку» |
| Проверки по расписанию | «каждый день в 9 проверяй цену на AirPods на озоне и скажи, если подешевеют», «следи за ценой на …», «какие проверки в браузере», «отмени проверку цены на …» |
| Окно агента | «покажи браузер», «сверни браузер», «что с поиском», «останови задачу в браузере» |
| Кнопка «Джарвис» в браузере | то же, что сказать «Джарвис» |

## Свои сценарии

Фраза → набор действий: трей → «Мои сценарии…» (файл `data/scenarios.toml`, перечитывается сам). Пример:

```toml
[[scenario]]
name = "Режим фокуса"
phrases = ["режим фокуса", "хочу поработать"]
say = "Режим фокуса, сэр. Не отвлекаю."
steps = [{ minimize_all = true }, { open = "spotify" }, { command = "помодоро" }]
```

Шаги: `open` (название, путь, `steam://…`), `url`, `close`, `say`, `reaction`, `wait`, `timer`, `media`, `music`,
`search`, `minimize_all`, `command` (любая команда Джарвиса).
